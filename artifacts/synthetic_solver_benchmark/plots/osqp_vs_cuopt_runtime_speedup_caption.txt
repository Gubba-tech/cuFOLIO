Synthetic LP/QP benchmark: OSQP versus direct NVIDIA cuOpt. OSQP 1.0.5 (QDLDL (OSQP builtin algebra)) ran on Intel(R) Xeon(R) 6530P; cuOpt 26.4.0 with CUDA 13.2 ran on NVIDIA RTX PRO 6000 Blackwell Server Edition, 595.71.05, 97887 MiB. Central estimates are medians across 3 registered seeds; shaded bands show the seed interquartile range. End-to-end timing begins with canonical arrays resident in host memory and includes backend conversion, setup, transfer where applicable, numerical solve, result extraction, and canonical correctness reconstruction. Only paired repetitions with strict optimal status, matching canonical instance hashes, and all canonical correctness gates passing enter timing and speedup summaries; failures and timeouts are excluded and marked. Speedup is OSQP time divided by cuOpt time, so values above one mean cuOpt is faster. Results apply only to the registered sparse synthetic problem families, dimensions, tolerances, software versions, and measured hardware.
