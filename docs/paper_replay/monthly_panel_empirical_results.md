# Monthly Panel Empirical Results

## Data

Sprint 15 uses the external `dfall_for_test.csv` monthly stock-characteristic
panel. The raw file is not committed to this repository.

- Coverage: 2000-01-31 through 2022-12-31, 276 complete months.
- Rows: 241,347 and 1,089 unique assets.
- Average stocks per month: 874.45; minimum 664, median 877.5, maximum 1,048.
- Characteristics: 35 fields are available; the 33 default paper-style fields
  are used in the managed-portfolio construction.
- Managed portfolios: 33 characteristic sorts x 10 bins = 330 portfolios.
- Source path used for the run:
  `/lustre/nvwulf/home/weicdeng/PortOpt-IPCA-GPU/data/dfall_for_test.csv`.

Characteristics are sorted at month `t` and their managed-portfolio returns are
realized at month `t+1`. Therefore the final replay date is 2022-11-30 even
when the requested panel end date is 2022-12-31.

## Method

The workflow converts characteristic-sorted decile portfolios into a managed
portfolio return table, estimates rolling PCA factors, and solves a homogeneous
max-Sharpe QP in factor space. PCA mapping `V` maps factor weights to managed
portfolio weights; it does not recover individual stock weights.

- Baseline PCA: K=6; sensitivity: K=2, 3, 4, 5, 6.
- Regularization baseline: `lambda_l1=1.7e-4`, `lambda_l2=1e-3`.
- Lambda grid: L1 in `[0, 1e-6, 1.7e-4, 1e-3]`; L2 in
  `[0, 1e-6, 1e-3, 2.9e-2]`.
- Short budget: 0.2.
- Explicit variable bounds: `[-0.08, 0.08]`.
- CPU backend: OSQP.
- GPU backend: direct cuOpt on the B40 node; no CPU fallback.

## Lambda Sensitivity

The 4 x 4 K=6 lambda grid uses 12 controlled 2020 windows per configuration.
The highest controlled-sample Sharpe was 0.644076 at `(lambda_l1, lambda_l2) =
(0, 0)`. The baseline pair `(1.7e-4, 1e-3)` produced Sharpe 0.643650, while
the largest L2 value, `2.9e-2`, produced Sharpe values around 0.595. These
differences are descriptive only because the grid is not a full 35-window OOS
comparison and does not establish a regularization choice for the paper.

## Interpretation

The workflow successfully produces empirical managed-portfolio QP results on
the uploaded panel. The 2020 OSQP and B40 cuOpt baselines agree closely in
returns and constraints, while the cuOpt run reaches all 35 windows directly
on the GPU node. The K sensitivity is sample-dependent, and the controlled
lambda grid shows only small changes near the baseline pair except at the
largest L2 value.

These are observations about this panel, portfolio construction, rolling
windows, and solver configuration. They are not claims about the original
paper's estimator or about general QP performance.

## Limitations

- Full original paper replication is not claimed.
- Full IPCA, RP-PCA, or AP-Trees replication is not claimed.
- Old-solution parity is not claimed without old weights and objectives.
- The data start in 2000, so exact 2005-start 20-year lookback is impossible.
- No global QP speedup is claimed.
- The existing Mean-CVaR LP workflow was not changed.
